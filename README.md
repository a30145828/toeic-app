# 多益單字與文法練習 App 📘

目標多益 600 分、英文基礎比較弱的人也能每天輕鬆練習的網頁 App。
**不用安裝、不用註冊**，打開網頁就能用，學習紀錄存在你自己的瀏覽器裡。
想換裝置也不遺失紀錄的話，可以另外設定免費的雲端同步（選用，見「四、雲端同步設定」）。

## 有哪些功能？

| 功能 | 說明 |
|---|---|
| 🧭 程度測驗 | 第一次使用時可以先做約 39 題的測驗（單字 30 題＋文法 9 題），分析你大概認識多少單字、各等級和主題的掌握率、文法弱點，並建議從哪個等級開始。答錯的字會優先排進每日新單字，答對的字直接排進複習。之後也可以在「設定」重新測驗。 |
| ✅ 每日任務 | 每天先複習「今天到期」的單字，再學 20 個新單字（可在設定改成 5／10／15／20／30 個）。全部完成會打勾並顯示鼓勵訊息。待複習超過 80 個時，新單字會自動減半並提醒你。 |
| 📚 2000 個多益單字 | Level 1 基礎 800 個、Level 2 進階 700 個、Level 3 衝刺 600 有 500 個。每一級再分成辦公室、會議、人事、出差、餐廳、購物、財務、製造、行銷 9 個主題，由簡單到難排列。 |
| 🃏 單字卡 | 英文、詞性、中文、KK 音標、簡單例句和中文翻譯，按 🔊 就會朗讀（使用瀏覽器內建的英文語音）。 |
| 📝 四種題型 | 英選中、中選英、聽音選意思、拼字。 |
| 🔁 間隔重複 | 使用 SM-2 記憶演算法安排複習時間：答對的字會隔越來越久才出現，答錯的字隔天就會再出現，而且當下過幾題就會再練一次。 |
| ✏️ 文法練習 | 200 題多益 Part 5 風格單句填空，涵蓋 9 個常考主題（詞性、時態、介系詞、連接詞、代名詞、被動語態、不定詞與動名詞、比較級、關係代名詞），每題都有中文翻譯和解析，還有「錯題複習」。 |
| 📈 學習統計 | 連續學習天數、已學會單字數、各等級和各主題完成度、近 7 天練習量。 |
| 💾 儲存與備份 | 紀錄存在瀏覽器的 IndexedDB 資料庫，「設定」頁會顯示存在哪裡、用了多少、還剩多少空間，也可以申請「永久保存」。另外可以匯出成 JSON 檔，換裝置時再匯入。 |
| ☁️ 雲端同步（選用） | 設定 Firebase 後可以用 Google 帳號登入，紀錄自動同步到雲端，多台裝置的進度會自動合併。 |

> 所有例句和文法題都是為這個 App 原創的，不是官方考題，也不是從市售單字書複製的。

## 程度測驗怎麼判斷？

- 每個等級抽 10 個字（9 個主題都會抽到），由簡單到難出題。
- 不會的題目請按「🤔 不知道」，不要用猜的。系統計算掌握率時會扣掉「猜對」的機率（4 選 1，大約每答錯 3 題就有 1 題是猜對的）。
- 第一個掌握率低於 80% 的等級，就是建議的起點。例如 Level 1 有 90%、Level 2 只有 40%，就建議從 Level 2 開始。
- 按「套用」後：
  1. 新單字從建議的等級開始，學完後面的等級後會再回頭補前面的。
  2. 起點以內答錯或不知道的字，會最先出現在每日新單字。
  3. 答對的字直接排進幾天後的複習，再答對一次就算學會。

## 一、在電腦上開啟

1. 在這個 GitHub 頁面按綠色的 **Code** 按鈕 → **Download ZIP**，下載後解壓縮。
2. 打開解壓縮後的資料夾，**用滑鼠雙擊 `index.html`**，就會用瀏覽器開啟 App。
   - 建議使用 **Chrome** 或 **Edge**（語音朗讀效果最好）。
3. 開始練習！學習紀錄會自動存在這台電腦的這個瀏覽器裡。

> 💡 小提醒：所有檔案（`index.html`、`app.js`、`style.css`、`grammar.js`、`words-level1.js`…）都要放在**同一個資料夾**，App 才能正常運作。

## 二、部署到 GitHub Pages，用手機練習

GitHub Pages 可以免費把這個 App 變成一個網址，手機打開網址就能用。

### 步驟

1. 登入 GitHub，打開這個專案（repository）的頁面。
2. 點上方的 **Settings（設定）**。
3. 左邊選單點 **Pages**。
4. 在 **Build and deployment** 底下：
   - **Source** 選 **Deploy from a branch**
   - **Branch** 選 **main**（或你放程式的分支），資料夾選 **/ (root)**，按 **Save**。
5. 等 1～2 分鐘後重新整理頁面，上方會出現網址，長得像：
   `https://你的帳號.github.io/toeic-app/`
6. 用手機打開這個網址就可以開始練習了！

> ⚠️ 如果專案是「私人（Private）」的，免費帳號可能無法使用 GitHub Pages。可以到 Settings → General 最下面把專案改成 Public。

### 把 App 安裝到手機（PWA，免費）

這個網頁可以直接「安裝」成手機 App：主畫面有自己的圖示、打開是全螢幕、**沒有網路也能練習**（有網路時會自動同步雲端並更新到最新版）。不用上架、不用付費。

- **Android（Chrome）**：打開網址 → App 的「設定」頁按「📲 安裝 App」；或按右上角「⋮」→「**安裝應用程式**」。
- **iPhone（Safari）**：打開網址 → 按下方的「分享」按鈕 →「**加入主畫面**」→「加入」。
- **電腦（Chrome／Edge）**：網址列右邊會出現「安裝」圖示，點一下就能安裝成電腦 App。

> 網站更新後，App 會在背景下載新版本，**下一次打開**時就會是新版。

### 重要：學習紀錄存在哪裡？

- 紀錄存在「**這台裝置的這個瀏覽器**」裡的 **IndexedDB 資料庫**（名稱 `toeic600`）。到 App 的 **設定 → 💾 資料儲存位置** 可以看到：
  - 用哪個瀏覽器、哪個網站存的
  - 學習紀錄有多大、這個網站用了多少空間、瀏覽器允許的上限、還剩多少
  - 是否已開啟「永久保存」（按 **🔒 申請永久保存**，瀏覽器空間不足時就不會自動刪除紀錄）
- 2000 個單字全部學完，紀錄也只有幾百 KB，空間非常足夠。
- 舊版 App 存在 localStorage 的紀錄，第一次打開新版時會**自動搬到 IndexedDB**，不用做任何事。
- **沒有設定雲端同步時**，電腦和手機的紀錄不會同步。換手機、清除瀏覽器資料前，請到 **設定 → 學習紀錄備份 → 匯出備份** 存一份 JSON 檔，再到新裝置按 **匯入備份**。
- iPhone 的 Safari 若很久（約 7 天以上）沒打開這個網站，可能會清掉網站資料，建議**加到主畫面**使用、開啟永久保存，並設定雲端同步或定期匯出備份。
- 不要在 LINE、Facebook 的內建瀏覽器裡使用，紀錄很容易被清掉。

## 三、新增單字

單字依等級放在不同檔案：

```
words-level1.js   ← Level 1 基礎（800 個）
words-level2.js   ← Level 2 進階（700 個）
words-level3.js   ← Level 3 衝刺 600（500 個）
```

### 在現有等級加單字

用記事本（Windows）或文字編輯（Mac）打開檔案；更推薦免費的 [VS Code](https://code.visualstudio.com/)，比較不容易打錯。
找到想放的主題（例如 `office:` 辦公室），在清單裡加一行：

```js
      ["scanner", "n.", "掃描器", "ˋskænɚ", "Please use the scanner next to the printer.", "請使用印表機旁邊的掃描器。"],
```

每個單字一定要剛好 **6 個欄位**，順序是：

| 順序 | 內容 | 範例 |
|---|---|---|
| 1 | 英文單字（小寫） | `"scanner"` |
| 2 | 詞性 | `"n."`、`"v."`、`"adj."`、`"adv."`，多個詞性用 `/` 隔開，例如 `"n./v."` |
| 3 | 中文意思 | `"掃描器"`，多個意思用全形分號隔開，例如 `"檢查；確認"` |
| 4 | KK 音標（**不要**加 `[ ]`） | `"ˋskænɚ"` |
| 5 | 英文例句 | `"Please use the scanner next to the printer."` |
| 6 | 例句中文翻譯 | `"請使用印表機旁邊的掃描器。"` |

⚠️ 新手最常犯的錯：
- 每個欄位都要用**半形雙引號** `"` 包起來，欄位之間用**半形逗號** `,` 隔開。
- 每一行最後要有逗號 `,`；但**清單裡最後一個單字的後面不要加逗號**。
- 同一個英文單字不能重複（就算在不同等級也不行）。
- 主題名稱只能用：`office`（辦公室）、`meeting`（會議）、`hr`（人事）、`travel`（出差）、`restaurant`（餐廳）、`shopping`（購物）、`finance`（財務）、`manufacturing`（製造）、`marketing`（行銷）。

### 新增一個新等級（例如 Level 4）

1. 複製 `words-level3.js`，把新檔案改名為 **`words-level4.js`**（放在同一個資料夾）。
2. 打開新檔案，把開頭改成：
   ```js
   addWordLevel({
     level: 4,
     name: "衝刺 700",
     topics: {
       office: [
         ["subcontractor", "n.", "轉包商；下游承包商", "ˏsʌbˋkɑntræktɚ", "We hired a subcontractor to install the windows.", "我們找了轉包商來安裝窗戶。"]
       ],
       meeting: [
         // …在這裡放更多單字
       ]
     }
   });
   ```
3. 存檔後重新整理 App，就會**自動讀到** Level 4，不需要改其他程式。之後還可以繼續加 `words-level5.js`、`words-level6.js`……（檔名的數字要連續）。

> 💡 App 會依序嘗試載入 `words-level1.js`、`words-level2.js`…直到找不到下一個檔案為止，所以在瀏覽器的開發者工具裡看到一筆「找不到 words-level4.js」的訊息是正常的。

### 檢查有沒有打錯

改完之後一定要檢查：

- **方法 1（最簡單）**：打開 App → **設定** → 看最下面的「**資料檢查**」，會顯示各等級的單字數，以及格式錯誤或重複的單字。
  如果 App 整個打不開或單字變少，通常是逗號或引號打錯了。
- **方法 2（有安裝 [Node.js](https://nodejs.org/) 的話）**：在專案資料夾執行
  ```
  node tools/check-data.js
  ```
  會列出每個等級、每個主題的數量，並找出重複單字和格式錯誤。

如果有部署到 GitHub Pages，把修改後的檔案上傳（commit）到 GitHub，等 1～2 分鐘手機重新整理就會更新。

### 新增文法題

打開 `grammar.js`，照著現有題目的格式加一題：

```js
  {
    topic: "介系詞",            // 只能是：詞性、時態、介系詞、連接詞、代名詞、被動語態、不定詞與動名詞、比較級、關係代名詞
    q: "The shop opens ____ 9 a.m.",   // 空格用 4 個底線 ____
    options: ["at", "in", "on", "for"],
    answer: 0,                  // 正確答案的位置：0=A、1=B、2=C、3=D
    zh: "這家店早上九點開門。",
    explain: "時刻要用 at。"
  },
```

## 四、雲端同步設定（選用）

GitHub Pages 只能放網頁，沒辦法存帳號資料，所以雲端同步要搭配 Google 的 **Firebase**（免費方案，有 1 GB 的資料庫空間，這個 App 每個人只用幾百 KB）。
Firebase 專案要用你自己的 Google 帳號建立，大約 10 分鐘：

### 步驟 1：建立 Firebase 專案
1. 打開 <https://console.firebase.google.com/>，用 Google 帳號登入。
2. 按「**新增專案**」（Create a project），名稱隨意（例如 `toeic-app`），Google Analytics 可以關掉，按「建立專案」。

### 步驟 2：開啟 Google 登入
1. 左邊選單「**建構（Build）→ Authentication**」→ 按「開始使用」。
2. 「**登入方式（Sign-in method）**」分頁 → 選 **Google** → 打開「啟用」→ 選擇你的支援電子郵件 → 儲存。
3. 「**設定（Settings）→ 已授權網域（Authorized domains）**」→ 按「新增網域」，輸入你的 GitHub Pages 網域，例如：`a30145828.github.io`（不用加 https 和後面的路徑）。

### 步驟 3：建立資料庫
1. 左邊選單「**建構 → Firestore Database**」→ 按「建立資料庫」。
2. 位置選 `asia-east1（台灣）`，模式選「**以正式版模式啟動**」（production mode）。
3. 建好後到「**規則（Rules）**」分頁，把內容整個換成下面這段，按「**發布**」：

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 每個人只能讀寫自己的學習紀錄
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

> ⚠️ 一定要設定這個規則。這樣每個人登入後只能看到自己的紀錄，別人看不到。

### 步驟 4：把設定貼到 cloud-config.js
1. 按左上角齒輪「**專案設定（Project settings）**」→「一般」分頁最下面「你的應用程式」→ 按 **`</>`（網頁）** 圖示。
2. 應用程式暱稱隨意輸入，**不用**勾選 Firebase Hosting，按「註冊應用程式」。
3. 畫面會出現一段 `const firebaseConfig = { ... }`，把其中的 `apiKey`、`authDomain`、`projectId`、`appId` 四個值，貼到專案裡的 **`cloud-config.js`**：

```js
window.CLOUD_CONFIG = {
  apiKey: "AIza......",
  authDomain: "toeic-app-xxxxx.firebaseapp.com",
  projectId: "toeic-app-xxxxx",
  appId: "1:1234567890:web:abcdef......"
};
```

4. 把修改後的 `cloud-config.js` 上傳（commit）到 GitHub，等 1～2 分鐘 GitHub Pages 更新。

> 💡 `apiKey` 不是密碼，放在網頁裡是正常的；資料的安全是靠步驟 3 的規則保護。

### 步驟 5：登入
用**網址**打開 App（直接開電腦上的 index.html 無法登入）→ **設定 → ☁️ 帳號與雲端同步 → 使用 Google 帳號登入**。

- 登入後，這台裝置的紀錄會上傳到雲端；之後每次練習，停止作答約 10 秒就會自動同步。
- 在另一台裝置登入同一個 Google 帳號，兩邊的進度會**自動合併**（每個單字保留較新的紀錄，不會互相覆蓋）。
- 「清除所有學習紀錄」和「匯入備份」在登入時會一併更新雲端。
- iPhone 加到主畫面的模式下如果登入視窗打不開，請先用 Safari 直接開網址登入。

## 小知識：「已學會」怎麼算？

每個單字都有自己的複習排程（SM-2 演算法）：
- 第一次學會 → 隔天複習
- 再答對 → 6 天後複習
- 再答對 → 間隔越拉越長（約 2 週、1 個月…）
- 任何一次答錯 → 重新從隔天開始

**連續答對 3 次**（代表已經隔了好幾天還記得）就會算進「已學會」。
